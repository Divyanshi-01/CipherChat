# CipherChat

Live Demo: https://cipherchat-frontend.onrender.com/login

CipherChat is a browser-based encrypted messaging app with a dark, minimal UI and browser-managed identities. It generates local key-based identities in the browser, keeps private keys local, and relays only encrypted message data through the backend.

## Tech Stack

- Spring Boot
- Thymeleaf
- WebCrypto
- Render

## How To Use

1. Open the live demo link.
2. Create or restore an identity.
3. Continue to chat and start messaging.
